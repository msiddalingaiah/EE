# Osprey samples

Native Osprey projects (`.osprey`, see [docs/format.md](../../docs/format.md)) and libraries
(`.ospreylib`).

`TA7358A.osprey` is the import of the Eagle pair in `../eagle/`. A test keeps the two in step:
it fails if the importer or the writer would now produce something different. After an
intended change to either, regenerate the sample and review the diff:

```sh
npm run samples
```

`madhu.ospreylib` started as the import of the Eagle library `../eagle/madhu.lbr` and is
edited in Osprey since, so it isn't regenerated: the test only checks that it is a library
file in the canonical layout whose components' symbols and footprints all exist.

`wwvbfind.osprey` is the WWVB finder (ATtiny412, MPF102/2N3904 front end, 20 MHz Pierce
oscillator): a schematic and board placement generated from a circuit description by a
script, as a first test of building designs with Claude, and placed with the placement toolkit
(`src/edit/arrange.ts`): connectors on the edges, blocks beside the pins they connect to,
rotations chosen by airwire length and crossings, then improved by small moves and swaps
(`src/edit/improve.ts`), then laid out again by hand on a smaller board (44.46 x 27.46 mm).
The 2-pin headers (VCC power, IN antenna, VOUT audio) have ground on pin 1; the UPDI header is UPDI, GND, VCC from pin 1. Its parts are grouped in blocks: Power, Preamp, MCU (with ADC-bias, Filter and LED inside) and Oscillator.

`wwvbfind-placed.osprey` is `wwvbfind.osprey` with its routing taken out, placed block by block
by autoplace (`src/edit/autoplace.ts`, the Blocks panel's Place button), unrouted: a file to
open beside the hand layout. A test regenerates it (`npm run samples`); review the diff.

`wwvbfind2.osprey` is a design change to wwvbfind, unrouted, its board as it was with the new
footprints parked beside it (press Place in the Blocks panel). A second MPF102 (Q3) buffers the
NPN stage as a source follower: C5 (10n) couples the collector to its gate, R7 (1M) holds the
gate at ground, R15 (2.2k) sets its bias. The ADC bias no longer comes from a VCC divider
(R8, R9, C6 are gone): a 10k trimpot (R16, RM-065) across R15 takes a share of the source
voltage, and C14 (100n) from the source to the wiper carries the signal, so the wiper goes
straight to the ADC pin. Preamp is split into stages: Input (Q1), Amp (Q2 and the tank) and
Buffer (Q3), with the VCCA filter (R10, C7) in Preamp itself. `wwvbfind2-placed.osprey` is it placed by autoplace (regenerated by
`npm run samples`).

`wwvbfind2-gen.osprey` is wwvbfind2's schematic generated from its block description,
`samples/blocks/wwvbfind2.blocks` (`osprey generate`): the same netlist as the hand-drawn
schematic, each block in its own area, with the footprints parked beside an empty board (Place
lays them out). A test regenerates it (`npm run samples`), so a change to the generator shows as
a diff here; review it.

`wwvbfind2-hand.osprey` is wwvbfind2 laid out by hand, a benchmark for autoplace: the same
block order along a 16.4 mm strip, but every block's parts turned so the signal runs straight
through (no airwires cross), and the title and date at the board's end between the holes.

The JFET source follower drives the 2N3904's base directly: its source voltage biases the
transistor, so there is no coupling capacitor or base divider. The emitter's bypassed
resistor (R6, 1k) keeps the collector current near 1 mA for a typical MPF102; a JFET with a
small pinch-off voltage may need a larger R2.
